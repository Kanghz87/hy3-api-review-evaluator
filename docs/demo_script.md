# 两分钟 Demo 录制脚本

目标：在 120 秒内展示一次真实 Hy3 审查和质量评估，不显示 API Key。

建议录制“浏览器操作 + 中文旁白”，不需要露脸或逐行讲解源码，也不用重新录人工标注过程。
先完整录一遍实际操作，再仅对等待模型的片段加速，并标注“等待过程已加速”。

**当前准备状态（2026-09-14）**：最新版真实预检已完成，5 条发现、92.50 分、耗时
102.10 秒；页面与 CSV 证据导出已验证。无需为了准备录制再次执行预检命令。
结果详见 [真实预检记录](../reports/demo_preflight_0_2_1.md)。正式网页运行会产生新调用，
分数不必与预检相同。

## 录制前准备

1. 完成 `.env` 配置，并确认页面侧栏只显示“Hy3 API Key: 已配置”。
2. 建议沿用 `high` 推理强度，保持与当前预检条件一致；不要为了缩短视频而反复付费重跑。
3. 仅在后续网络、配置或代码发生变化且需要重新验证时，才执行下列真实预检命令。
   该命令会调用 Hy3 两次并产生 token 用量；本次已完成，不用重复执行：

   ```powershell
   Set-Location D:\Hy3ApiReviewEvaluator
   $env:HY3_TIMEOUT_SECONDS = '180'
   $env:HY3_REASONING_EFFORT = 'high'
   .venv\Scripts\python.exe scripts\run_hy3_smoke.py `
     --demo --force --run-token-budget 60000
   ```

   输出写入被 Git 忽略的 `results/private/demo-preflight-0.2.1.json`。不加 `--force` 时可能只读取已有
   预检结果，不能证明当前网络和服务可用。使用该次实际耗时安排录制，不要期待某个固定分数。
4. 打开 PowerShell，按顺序执行以下命令启动应用。若旧版本仍在运行，先在旧窗口按
   `Ctrl+C` 停止，再重新启动；不要在正在使用的应用之外重复启动多个实例：

   ```powershell
   Set-Location D:\Hy3ApiReviewEvaluator
   $env:HY3_TIMEOUT_SECONDS = '180'
   $env:HY3_REASONING_EFFORT = 'high'
   .\.venv\Scripts\streamlit.exe run app.py
   ```

5. 在浏览器打开终端显示的本地地址（默认 `http://localhost:8501`），准备上传文件
   `D:\Hy3ApiReviewEvaluator\datasets\specs\hard-15-mixed-security.yaml`。
6. 浏览器缩放到 80%～90%，关闭通知和包含 Key 的终端窗口。
7. 录制范围只选浏览器页面，不录 `.env`、TokenHub 控制台或 PowerShell 历史。

## 时间轴和台词

### 0～12 秒：问题与定位

画面停在页面标题和非官方声明。

台词：

> 这是 Hy3 API Review Evaluator。它解决两个问题：OpenAPI 人工审查容易遗漏，而大模型
> 报告又可能错误定位或编造证据。本项目既生成审查，也评价审查是否可信。

### 12～28 秒：上传和选择重点

- 审查重点选择“安全性”。
- 上传 `hard-15-mixed-security.yaml`。

台词：

> 我上传一份合成的 OpenAPI 3.1 文档。文件只作为数据解析，远程引用不会下载，文档中的
> 指令不会执行。

### 28～43 秒：确定性检查

滚动到确定性检查表，指出 HTTP、DELETE 鉴权、路径参数和错误响应。

台词：

> 调用模型前，本地代码已经给出可复现证据。这些 finding 之后会成为模型不能绕过的事实
> 锚点。

### 43～76 秒：真实 Hy3

点击“运行 Hy3 审查并评估报告”。等待时保持 spinner 可见。

台词：

> 现在第一次调用 Hy3 生成严格 JSON 审查，第二次让 Hy3 按六维 Rubric 评价报告。每次调用
> 都先检查 token 预算，整个实验最多 85 万 token。

本次 0.2.1 高推理强度预检耗时 102.10 秒，不代表下一次固定耗时。可在后期只加速等待区间，
例如约 4 倍速，并显示“等待过程已加速”，把最终成片压缩到本段约 33 秒；不删除错误或
结果画面，也不要把缓存结果说成刚刚调用。

### 76～100 秒：评分与证据

- 展示总分、结论和六维表格。
- 展开一个 finding，展示 JSON Pointer、quote 和绿色“匹配”。

台词：

> 评分关注事实、定位、严重程度、证据、建议和幻觉。这里的 pointer 和 quote 会回到原文
> 逐项核验；模型打高分也不能绕过本地证据检查。证据存在不代表结论一定正确，语义判断
> 仍需要模型和人工复核。

### 100～113 秒：下载与复现

点击 JSON 或 CSV 下载按钮，但不打开本机敏感目录。

台词：

> 结果支持 JSON、CSV 下载。新版本地回归保持 20 组排序全部正确，历史人工实验与新版
> 修订结果分开保存，大家可以复算和检查。

### 113～120 秒：结束声明

滚回顶部非官方声明。

台词：

> 这是腾讯犀牛鸟计划个人实战作品，并非腾讯官方软件。

## 录制后检查

- 总时长不超过 2 分钟。
- 画面和音频中没有 Key、Authorization Header、`.env` 内容或 TokenHub 余额。
- 确实展示 `model=hy3` 的运行结果或脱敏验证记录。
- 人工一致性只称为 33 条单人合成样本结果，不冒充全量或多人结论；不把相关系数说成准确率。
- 如果展示 0.948 或 4.17，必须注明是 v1.0 历史实验，不是当前 v1.1 的新验证成绩。
- 视频说明附仓库链接、运行命令、许可证和非官方声明。
- 导出成一个不超过 120 秒的 MP4，建议 1080p；确认界面文字和旁白清楚。可先发给开发搭档
  检查，不要直接提交未检查的录屏。
